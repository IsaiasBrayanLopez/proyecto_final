[27] Text: El presente proyecto consiste en el desarrollo de un Catálogo Automotriz interactivo construido con el framework Flutter y el lenguaje de programación Dart. Esta aplicación móvil multiplataforma permite a los usuarios explorar un inventario detallado de vehículos, consultar fichas técnicas, visualizar galerías y filtrar opciones mediante una interfaz fluida, moderna y responsiva. | Imgs: []
[28] Text: Este desarrollo se enmarca dentro de las actividades prácticas de la Unidad 3: Manejo de Estados, Arquitectura y Servicios. El objetivo principal de esta etapa académica es transicionar de la creación de interfaces estáticas hacia el diseño de aplicaciones dinámicas, escalables y estructuradas bajo estándares profesionales de ingeniería de software, garantizando una correcta separación de responsabilidades entre la vista y los datos. | Imgs: []

[145] Text: CONCLUSIONES | Imgs: []
[146] Text: El desarrollo de este Catálogo Automotriz permitió llevar a la práctica conceptos esenciales de Flutter y Dart que resultan críticos en el ciclo de vida de una aplicación real. Entre los aprendizajes técnicos más concretos destaca la implementación del patrón Factory dentro de los modelos de datos para deserializar objetos JSON de manera segura y eficiente, así como el dominio de la programación asíncrona mediante async/await para evitar bloqueos en la interfaz durante la lectura de archivos. Asimismo, el uso estratégico de setState permitió comprender a fondo el ciclo de reconstrucción del árbol de elementos, mientras que la creación de widgets reutilizables redujo la duplicidad de código y mantuvo la consistencia visual en todas las vistas. | Imgs: []
[147] Text: A nivel metodológico, el trabajo colaborativo mediante Git fue un pilar fundamental para el éxito del proyecto. La gestión de ramas independientes para cada funcionalidad, la resolución de conflictos de fusión (merge) y la integración continua del código permitieron que el equipo trabajara de forma paralela sin comprometer la estabilidad de la rama principal, replicando las dinámicas de un entorno profesional de desarrollo de software. | Imgs: []
[148] Text: Finalmente, este proyecto representa un cimiento sólido para abordar desarrollos de mayor complejidad en el futuro. Haber dominado la arquitectura por capas y el manejo de flujos asíncronos con datos locales prepara directamente el terreno para integrar, en etapas posteriores, el consumo de APIs RESTful remotas, bases de datos en la nube y gestores de estado avanzados, consolidando las bases necesarias para construir productos de software robustos y listos para producción. | Imgs: []
